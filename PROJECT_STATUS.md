# Статус проекта «Форма»

Обновляется после каждого значимого изменения.

## Что это
Веб-приложение-дневник питания (Node.js, Vite, React, TanStack Start, Nitro, пресет `node-server`).
Дневник хранится в браузере. Сервер нужен для отдачи сайта и вызовов DeepSeek (фраза дня, фото блюда).

## Где что
- Репозиторий: `vladadmin76/form`, ветка `main`.
- Развёртывание на сервер: `docs/server.md` (nginx, systemd, домен, HTTPS, обновление).
- Ключ `DEEPSEEK_API_KEY` только в `/opt/forma/.env` на сервере, в репозиторий не попадает.
