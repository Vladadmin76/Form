# Напоминания в Telegram

Бот присылает напоминания (вода, завтрак/обед/ужин) в личный чат, даже когда «Форма» закрыта.
Дневник на сервер не попадает: он остаётся в браузере телефона. На сервере хранится только привязка чата,
часовой пояс и расписание напоминаний (база Cloudflare D1, бесплатно).

## Один раз настроить

1. **Создать бота.** В Telegram откройте @BotFather → `/newbot` → имя и логин (заканчивается на `bot`).
   Скопируйте выданный токен. Никому не присылайте и в чат не вставляйте.
   Нужен отдельный бот для «Формы»: у одного бота может быть только один адрес вебхука.
2. **Токен в GitHub.** Репозиторий `form` → Settings → Secrets and variables → Actions → New repository secret:
   имя `TELEGRAM_BOT_TOKEN`, значение — токен бота.
3. **Право для базы.** Токену Cloudflare нужно право на базы D1: Cloudflare → My Profile → API Tokens →
   токен `forma-github` → Edit → добавить Permissions: Account → D1 → Edit → сохранить.
   (Если права нет, выкладка не ломается: в логе шага «Prepare D1 database» будет предупреждение,
   а в профиле «Бот пока не подключён к сайту».)
4. **Выложить.** Вкладка Actions → Deploy to Cloudflare Workers → Run workflow. Шаги выкладки сами создают базу `forma`,
   кладут токен бота в секреты Worker'а и сообщают Telegram адрес вебхука.

## Подключить в приложении

Профиль → Telegram → «Подключить бота» → «Открыть бота» → в Telegram нажать «Начать» (Start) → вернуться в «Форму»:
через несколько секунд появится «Подключено». Дальше: «Напоминать про воду» (с какого часа, до какого, как часто),
а завтрак/обед/ужин берутся из списка «Напоминания» выше (включённые). «Отправить проверку» присылает тестовое сообщение,
«Отключить» удаляет привязку (так же работает команда `/stop` в чате с ботом).

## Как это устроено

- Привязка по одноразовой ссылке `t.me/БОТ?start=ТОКЕН` (токен живёт 10 минут, хранится только его хеш, погашается одной командой).
  Вебхук принимает только запросы с секретным заголовком Telegram, только личные чаты.
- Вместо аккаунта: случайный секрет устройства в браузере (`forma-device`), на сервере его хеш.
  Если очистить данные сайта, привязку нужно сделать заново.
- Рассылка: расписание Cloudflare раз в 15 минут (`*/15 * * * *`, одно из 5 бесплатных). Время считается по часовому поясу телефона,
  сообщение может прийти с опозданием до 15 минут. Повторы исключены (ключи отправленного хранятся за вчера и сегодня).
- Если Telegram отвечает «бота заблокировали» или чата нет, либо 5 неудач подряд, отправка останавливается;
  в приложении появится «Подключить заново».
- Файлы: `server/routes/api/telegram/*` (маршруты и вебхук), `server/tasks/reminders/send.ts` (рассылка),
  `server/utils/tg.ts`, `src/lib/tg-schedule.ts` (расчёт расписания, есть тесты), `src/components/forma/telegram.tsx` (экран),
  `migrations/d1/001_telegram.sql`, `scripts/d1-prepare.mjs`, `scripts/telegram-setup.mjs`.

## Если что-то не работает

- «Бот пока не подключён к сайту»: нет секрета `TELEGRAM_BOT_TOKEN` в GitHub, не выложено после его добавления, либо не создалась база
  (смотрите шаг «Prepare D1 database» в Actions).
- Бот молчит после «Начать»: проверьте шаг «Set Telegram webhook» в Actions (красный крестик означает неверный токен).
- Токен утёк: в @BotFather `/revoke`, новый токен в секрет GitHub, снова Run workflow.
